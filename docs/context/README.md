# Proof of Value project context

These files are the durable conversational context for Proof of Value work:

1. [`POV_PROJECT_CONTEXT.md`](POV_PROJECT_CONTEXT.md) — current product
   direction, system boundary, implementation state, guardrails, and open
   decisions.
2. [`POV_DECISION_LOG.md`](POV_DECISION_LOG.md) — how the direction evolved and
   which earlier ideas are historical or deferred.
3. [`POV_MVP_CONTEXT.md`](POV_MVP_CONTEXT.md) — compact MVP-only snapshot.
4. [`CHATGPT_PROJECT_INSTRUCTIONS.md`](CHATGPT_PROJECT_INSTRUCTIONS.md) — a
   portable instruction block for chat surfaces that do not read `AGENTS.md`.

They were consolidated on 2026-07-31 from the app-managed ChatGPT project `PoV`
and its “Define Proof of Value MVP” thread. This repository is the canonical
implementation and context home; app-managed project mirrors are not separate
implementation checkouts.
