# Swarm contributor workstreams

**Active entry point — August 2026 market-entry foundation.** These five packets turn the [active plan](../plans/2026-08-04-001-feat-swarm-market-entry-foundation-plan.md) into bounded follow-up work. They describe the foundation as it exists today; they do not authorize live operations or settle the plan's Open Questions.

| Track | Current maturity | Primary boundary |
| --- | --- | --- |
| [AT account, provisioning, and publishing](at-account-and-publishing.md) | Proposed | Host provisioning authority is distinct from a member's write authority. |
| [Feed index and lifecycle](feed-index-and-lifecycle.md) | Proposed | AT records are canonical; admission, lifecycle, and PoV views are derived. |
| [PoV evaluation and settlement](pov-evaluation-and-settlement.md) | Proposed / blocked live proof | Fixtures, local Koinos evidence, Harbinger proof, and live settlement are separate gates. |
| [Moderation and operations](moderation-and-operations.md) | Proposed | Feed policy can exclude from Swarm; it cannot erase a public AT record. |
| [Product and research](product-and-research.md) | Proposed | A bounded invited cohort tests contribution rules and learning signals. |

## How to choose a packet

Read the packet's prerequisites, upstream contract IDs, and open questions before changing code. Start a discussion or issue with the packet name and a small proposed slice; do not assume ownership of a shared contract, policy, or live service. Each packet gives an objective verification surface and names the other tracks that must review a boundary change.

The [July parallel-workstream plan](../plans/2026-07-20-001-feat-parallel-prototype-foundation-plan.md) and its unit map remain protocol-history evidence. They are not the current contributor sequencing. The [roadmap](../../ROADMAP.md) and [contributor guide](../../CONTRIBUTING.md) link back here.

All work remains for a small open-source experiment: no token launch, investment product, fundraise, public beta, credentials, or live account/PDS operation is authorized by these packets.
