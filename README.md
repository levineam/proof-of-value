# Proof of Value

**Private working draft. Not for publication, investment use, or implementation reliance.**

This repository contains the version-one working white paper for **SWARM** (Stake-Weighted Autonomous Reward Mechanism), a proposed Proof of Value mechanism for distributing a predetermined token budget according to stake-weighted, contestable evaluations of AT Protocol content, with deterministic settlement on Koinos.

The current draft is [WHITEPAPER.md](WHITEPAPER.md). It describes a proposed reference architecture and mechanism, identifies open design questions, and intentionally does not claim a production deployment or settled economic parameters. Its factual protocol claims are grounded in the accompanying [primary-source audit](docs/source-audit.md); the mechanism remains a proposal.

The architecture infographic is stored at [assets/proof-of-value-architecture.png](assets/proof-of-value-architecture.png) and is governed by the auditable [diagram specification](docs/architecture-diagram-spec.md).
